Tools

Standalone quant-finance tools that run against a suite's saved context, rather than being locked into one suite.

How to use this

A context is a file called suite_context.json, written automatically every time one of the suites (Vol_Suite, Options_Suite, VaR_Tools_Simulations, sentiment-scanner) or the root orchestrator.py finishes a unified run. Think of it as a claim ticket: it records which ticker, expiration, and analysis a run already did, so a Tool can pick up right where that run left off instead of redoing the setup.

To use a tool, first run a suite's unified flow for the ticker you care about (from the Overview page's "Trigger a run" panel, choosing a unified target), then come back here once it finishes -- its context will show up in the list below and in each tool's context picker. Pick a context, choose a mode, and run.
