Backtesting Tool

Two backtests in one tool: a dealer-gamma-sign realized-vol study, or a multi-leg strategy P&L simulation. ← back to Tools

How to use this

A context comes from running a suite's unified flow (see the Overview page's "Trigger a run" panel) -- it records a ticker, expiration, and (if the run included an options chain scan) a list of recommended strategies. Pick the context for the run you care about below.

dealer_gamma_study tests whether dealer gamma sign (long vs. short) predicted subsequent realized volatility over that context's ticker/expiration/lookback window -- no strategy selection needed. strategy_pnl simulates one specific multi-leg strategy's profit/loss from an entry date to an exit (or expiration) date; pick the strategy from the context's own recommended list (populated by the Options Strategy Tool during that run) and give it an entry date (YYYYMMDD).
