Backtesting Tool

Five backtests in one tool: a dealer-exposure (live model) realized-vol study, a multi-leg strategy P&L simulation, a stock strategy backtest, an option strategy backtest, or broker-book accuracy. ← back to Tools

How to use this

A context comes from running a suite's unified flow (see the Overview page's "Trigger a run" panel) -- it records a ticker, expiration, and (if the run included an options chain scan) a list of recommended strategies. Pick the context for the run you care about below.

dealer_gamma_study tests whether the live dealer-exposure engine's gamma sign predicted subsequent realized volatility over that context's ticker/expiration/lookback window -- no strategy selection needed. The model selector only distinguishes the live model from the legacy sign models, which are retained for comparison only. strategy_pnl simulates one specific multi-leg strategy's profit/loss from an entry date to an exit (or expiration) date; pick the strategy from the context's own recommended list and give it an entry date.

stock_strategy_backtest runs a standard equity strategy (buy & hold, SMA cross, or momentum) over a date window and reports Sharpe / max drawdown / CAGR against a buy-and-hold benchmark. option_strategy_backtest runs a standard option strategy (long call/put, covered call, protective put, straddle, strangle) over a date window to expiry.
