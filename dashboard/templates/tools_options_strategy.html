Recommends multi-leg option strategies from a suite run's vol-regime and edge-strike chain scan. ← back to Tools

How to use this

A context comes from running a suite's unified flow (see the Overview page's "Trigger a run" panel) -- it is a snapshot of one run's ticker, expiration, and (if the run included an options chain scan) prior strategy output. Pick the context for the ticker/run you care about below.

cached mode reads back the strategies that run already computed and saved -- instant, no data-vendor calls. live mode re-runs the chain scan fresh against that context's ticker/expiration right now, which needs live data access and takes longer.
