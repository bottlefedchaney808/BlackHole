# Sentiment Scanner — Contested Narrative Detector + Options/Vol Correlation

## Project Identity
Real-time sentiment scanner that detects contested narratives (StockTwits) and cross-references options flow (ThetaData) plus swap activity (CME SDR).

## Key Facts
- **Root:** `C:\Users\bottl\FinancialDevelopment\sentiment-scanner\`
- **Python:** 3.11 (venv at `.venv`)
- **Package manager:** uv (pip installs via uv)
- **Terminal backend:** local (NOT Docker)
- **HTTP caveat:** httpx is blocked in sandbox — use `urllib` for HTTP calls

## File Layout
```
main.py                  — Entry point: scan loop + deep dive
```

## API Endpoints
- **ThetaData:** `https://api.potatohedge.com` — client ID/secret in `config.py`
- **StockTwits:** public API, no auth needed
- **CME SDR:** public swap data

## Scoring
- **CNS** (Contested Narrative Score): 0–100, threshold at 50
- **War Score:** float, threshold at 0.3
- **Thesis ratio:** bullish/bearish message ratio

## Workflow
1. `main.py` scans trending tickers from StockTwits
2. Scores messages for contested narrative
3. Above-threshold tickers get a deep-dive: options chain (ThetaData) + swap activity (CME SDR)
4. Correlation engine cross-references all three data sources

## Pitfalls
- Never run `scanner/*.py` from `scanner/` as CWD (`ModuleNotFoundError`). Run from the sentiment-scanner root.
- `gex_scanner` must not crash on a successful scan.
- Max pain / OI 404 is missing expiry OI, not a hard fail.
