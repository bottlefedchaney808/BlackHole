# FinancialDevelopment (Linux)

POSIX/Linux port of [FinancialDevelopment](https://github.com/bottlefedchaney808/FinancialDevelopment).

- **Windows spine (canonical `master`):** `bottlefedchaney808/FinancialDevelopment`
- **This repo:** the cloud-box Linux checkout. Full tree, Linux adaptations included.
- Do **not** merge this history onto Windows `master`. Linux deltas stay here (and on `chore/linux-cloud-checkout` of the Windows repo).

Python 3.12 via `uv` in `.venv`. Invoke as:

```bash
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python ...
```
