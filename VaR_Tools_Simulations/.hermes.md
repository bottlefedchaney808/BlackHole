# VaR_Tools_Simulations — Python VaR Toolkit

## Project Identity
Python reimplementation and extension of the VaRtools Excel toolkit (v2.6d).
Full-stack VaR engine covering correlated simulation, Monte Carlo, historical sim,
copulas, forex VaR, stress testing, and VaR aggregation — designed for real-money
use with live market data from ThetaData.
