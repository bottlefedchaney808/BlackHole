ARCHITECTURE HIGHLIGHTS
================================================================================

BACKWARD COMPATIBILITY:
  Existing code (backfill.py) works unchanged:
    loader = SwapsLoader()
    loader.upsert_trades(records)  # Defaults to data_source='DTCC'

  New code can use adapters explicitly:
    adapter = DTCCAdapter()
    loader.upsert_trades([t.to_dict() for t in adapter.fetch_trades()],
                         data_source=adapter)

PLUGGABLE DESIGN:
  Any adapter implementing DataSourceAdapter can be used:
    class CMEAdapter(DataSourceAdapter): ...
    class OTCAdapter(DataSourceAdapter): ...

  Adapters are interchangeable:
    for adapter in [DTCCAdapter(), CMEAdapter(), OTCAdapter()]:
        trades = adapter.fetch_trades(...)
        loader.upsert_trades(...)

SCHEMA VERSIONING:
  Each adapter can track format changes:
    DTCCAdapter.get_schema_version() -> 1
    CMEAdapter.get_schema_version() -> 1

  Enables future normalization changes without breaking compatibility.

DATA LINEAGE:
  Every trade records its source:
    SELECT data_source, COUNT(*) FROM swap_trades GROUP BY data_source

  Supports audits and source-specific analysis:
    SELECT * FROM swap_trades WHERE data_source = 'CME'

EXAMPLE 4: Multi-source ingestion

  from adapters.cme_adapter import CMEAdapter
  from db_loader import SwapsLoader

  adapters = [DTCCAdapter(), CMEAdapter()]
  loader = SwapsLoader()

  for adapter in adapters:
      trades = adapter.fetch_trades()
      loader.upsert_trades([t.to_dict() for t in trades], data_source=adapter)
